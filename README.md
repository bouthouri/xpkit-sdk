# @bouthouri/xpkit-core

Pure-TypeScript core for **XP Kit** — the versioned config schema (Zod), the gamification engine, and the storage-adapter + asset-ref interfaces. **Zero runtime dependencies; no React / React Native / storage libs.**

> 🚧 **Scaffold only.** The implementation is intern work. See, in the [`xpkit`](https://github.com/bouthouri/xpkit) repo:
> - `docs/INTERN-BRIEF.md` §5–§7 (architecture, constraints, config schema v1)
> - `docs/INTERN-TASKS.md` → **F1** (schema + interfaces), **F2** (engine)

Part of the XP Kit `track:kit`. Consumed by [`@bouthouri/xpkit-react-native`](https://github.com/bouthouri/xpkit-react-native) and the XP Kit app.
